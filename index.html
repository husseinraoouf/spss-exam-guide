Weeks 1 & 4 · Introduction

Statistics basics

Core definitions

  • Statistics: collecting, organizing, analyzing and interpreting data to make decisions.
  • Population: every outcome of interest. Sample: a subset of it.
  • Parameter describes a population (μ, σ, π). Statistic describes a sample (x̄, s, p).
  • Descriptive statistics organize, summarize and display data. Inferential statistics use a sample to draw conclusions about a population, using probability.

Types of variable

  • Qualitative (categorical): a label, e.g. gender, sector, rating.
  • Quantitative: a number. It is either discrete (you count it: family size, employees, branches) or continuous (you measure it: income, sales, age).
  • Nominal: categories with no order (gender, location). Ordinal: ordered categories (Excellent / Good / Poor).
  • Interval: equal steps, no true zero (temperature °C). Ratio: has a true zero (sales, income).

In SPSS Variable View, the Measure column is Nominal, Ordinal or Scale. Scale covers both interval and ratio.

Sampling techniques

  • Simple random: every member has an equal chance.
  • Stratified: split into groups (strata), then sample from each group.
  • Cluster: split into clusters, randomly pick whole clusters.
  • Systematic: every k-th member after a random start.
  • Biased examples: convenience sampling, voluntary response.

Weeks 2–3 · Numerical measures

Describing data with numbers

Central tendency

x̄ = Σx / n    μ = Σx / N
  • Median: sort the data and take the middle value (or the average of the two middle values).
  • Mode: the most repeated value.
  • With an outlier, report the median, not the mean. Outliers pull the mean.

Slide example: 81, 75, 66, 16, 90, 90 gives mean 69.67, median 78, mode 90. 16 is an outlier, so the median is the best measure.

Dispersion

Range = Max − Min
s² = Σ(x − x̄)² / (n − 1)    σ² = Σ(x − μ)² / N
s = √s²    IQR = Q3 − Q1

Slide example: 81, 75, 66, 84, 96 gives range 30, s² = 493.2 / 4 = 123.3, s = 11.1, Q1 = 70.5, Q3 = 90, IQR = 19.5.

SPSS always reports the sample versions (n − 1).

Position & box plot

  • Q1 = 25th percentile, Q2 = median, Q3 = 75th percentile.
  • Five-number summary: Min, Q1, Median, Q3, Max.
  • Outlier rule: below Q1 − 1.5·IQR or above Q3 + 1.5·IQR. SPSS marks these with ○, and extreme values (beyond 3·IQR) with ✱.
  • Shape: a longer right whisker means right (positive) skew.

Get every measure at once SPSS

AnalyzeDescriptive StatisticsFrequencies
  1. Move the scale variable (e.g. Sales) into the list.
  2. Untick Display frequency tables, since a scale variable gives hundreds of rows.
  3. Statistics…: tick Quartiles, Mean, Median, Mode, Std. deviation, Variance, Range, Min, Max, Skewness.
  4. Charts…: Histogram (optionally with a normal curve).

  2. Plots…: Boxplots "Factor levels together".
  3. The output gives Descriptives (mean, 95% CI, median, variance, SD, IQR, skewness) and a box plot.

Tables and graphs

Qualitative variable → frequency table

AnalyzeDescriptive StatisticsFrequencies

Classes must be mutually exclusive (each observation fits in exactly one class) and collectively exhaustive (every observation has a class). Relative frequency = frequency ÷ total.

Week 5 · Discrete probability distributions · Homework 2

Binomial distribution

Probability distribution rules

  • Every P(x) is between 0 and 1.
  • Outcomes are mutually exclusive.
  • The list is exhaustive, so ΣP(x) = 1.
μ = E(X) = Σ x·P(x)
σ² = Σ (x − μ)²·P(x)

Two coins: X = number of heads gives P(0) = ¼, P(1) = ½, P(2) = ¼.

Is it binomial? All four must hold

  1. A fixed, known number of trials n.
  2. Only two outcomes: success or failure.
  3. The same success probability π on every trial.
  4. Trials are independent.
μ = nπ    σ² = nπ(1 − π)    σ = √σ²

Compute it in SPSS

TransformCompute Variable
  1. In Data View, type any number in row 1 of an empty column. Compute needs at least one case.
  2. Target Variable: e.g. p1.
  3. Numeric Expression: PDF.BINOM(x, n, π) for P(X = x), or CDF.BINOM(x, n, π) for P(X ≤ x).
  4. In Variable View, set Decimals to 4, or the answer shows as .00.

The classic trapFor a discrete variable, "less than" and "at most" are different. "At least k" is 1 − CDF of k − 1, not of k.
Week 6 · Continuous probability distributions · Homework 3

Uniform and normal distributions

Uniform (a, b)

  • Rectangular shape, fully described by its min a and max b. Area = 1.
P(x) = 1/(b − a) for a ≤ x ≤ b
μ = (a + b)/2    σ = √((b − a)²/12)
P(X < x) = (x − a)/(b − a)

CDF.UNIFORM(x, a, b)

Bus wait U(0, 30): P(<25) = .8333, P(>25) = .1667, P(10–20) = .3333, μ = 15, σ² = 75, σ = 8.66.

Normal (μ, σ)

  • Bell-shaped, one peak, symmetric, total area = 1.
  • Asymptotic: the tails approach the x-axis but never touch it.
  • Fully described by μ and σ. Mean = median = mode.
z = (x − μ)/σ

CDF.NORMAL(x, μ, σ) gives P(X < x). For the standard normal Z, use CDF.NORMAL(z, 0, 1).

Empirical rule

RangeArea
μ ± 1σ≈ 68%
μ ± 2σ≈ 95%
μ ± 3σ≈ 99.7%

Battery life μ = 19, σ = 1.2: 68% fail between 17.8 and 20.2 hours, 95% between 16.6 and 21.4, and virtually all between 15.4 and 22.6.

Week 7 · Estimation & confidence intervals

Estimation and confidence intervals

Ideas

  • Statistics are known. Parameters are usually unknown, so we infer them.
  • Inference has two branches: estimation and hypothesis testing.
  • Point estimate: one value. x̄ estimates μ, p estimates π, s estimates σ.
  • Confidence interval: a range expected to contain the parameter at a stated confidence level. The significance level is α = 1 − confidence.
  • Margin of error = (upper − lower) / 2.

What changes the width

If you increase…ErrorInterval
sample size nsmallernarrower
confidence levellargerwider
αsmallernarrower
σ (spread)largerwider

Is a value "reasonable" for μ? Yes if it falls inside the interval, no if it falls outside.

CI for a mean SPSS

AnalyzeDescriptive StatisticsExplore
  1. Put the variable in Dependent List.
  2. Statistics…: Descriptives, and set the confidence interval for the mean (95, 90 or 99).
  3. Read 95% Confidence Interval for Mean: Lower / Upper Bound.

Alternative: AnalyzeCompare MeansOne-Sample T Test with Test Value 0. Options… sets the CI %.

CI for a proportion SPSS

AnalyzeDescriptive StatisticsFrequenciesBootstrap
  1. Tick Perform bootstrapping and set the confidence level.
  2. The Frequencies table gains a bootstrap 95% CI column for each percentage.
